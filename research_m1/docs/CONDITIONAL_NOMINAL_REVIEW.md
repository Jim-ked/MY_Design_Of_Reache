# 条件四维标称数值演示实施记录

唯一科学依据仍为M1_SINGLE_AUTHORITY.md。本文件仅记录E17人工裁定的实现、计算及验收范围，不是另一份模型规范。先在16L分支完成来源解释收口并运行36项基础回归，正常推送、快进合并后核验远端main为1a23c9907daeb9105ea612b9b9123b161f39dedf，再创建research/m1-conditional-nominal。此候选不合入main。

## 来源解释收口

154.45°是AD2.12跑道真方位，被用作条件LOC轴向，不是已直接测得的LOC精确航迹角。AD2.2/p1记载磁差7°W（2019）及年变率4′27″；保留年份与打印单位，不猜方向或外推磁差。约132.041m是所选条件轴线与公布TJ954间偏差，不能仅归因于跨AIRAC，也不是TSE或随机sigma。

公布IF至DME水平距9.21347NM，与D9.2的条件显示区间相容；IF参考站至入口16.74269km，与图示16.7km相容。条件FAF至入口11.16297km比图示11.1km多62.973m，单独±50m不闭合；将D6.2的±0.05NM显示区间传播后，入口距离区间[11070.37,11255.58)m与11.1km的[11050,11150)m有重叠。此为明确舍入假设下的有限检查，不是精确航迹认证。双跑道相对布局仅核对方向/量级，不从示意图制造精确间距。详见16L_LOC_REFERENCE_AUDIT.md及loc_reference_tests.json；没有发现程序选择错误，原几何坐标和长度未改。

精确公式与参数定义只记录在唯一依据的E17演示条目。实现用最低次数的RF1二次函数与后续直线、16L平飞/二次段/最终GP直线，解析返回h、h′和h″。16L连接长度由620m与条件FAF的高度闭合推导，未增加自由转接时长、截获器、控制律或高阶平滑。参数只在study.yaml的operations.conditional_nominal中配置，正式未知项继续为null。

统一使用s为水平沿程，T=t_entry+s/Vh，r=[c(s),h(s)]，v=Vh[c′e,c′n,h′]。共用新包time_map/invert_time和AircraftState接口；每个必要连接点分别求左右状态，位置差≤1e−5m、速度差≤1e−6m仅是浮点求值门限。允许曲率/h″阶跃，不把跨界差分当实际无限加速度。所有活动域外状态为空，不外推；相对位置/速度仅在共同活动域求值，不搜索最近点或计算任何风险。

时长差约94.134225s，只是两个条件速度下的持续时间差，不是正式进入时差或时间收益。16R初始下降角约1.6573°、TJ906后为3°；RF半径约4917.648m，115kt GS的零风等效协调坡度代理量约4.1510°。该量只由地速/水平曲率与标准重力计算，没有风/TAS/机型载荷证据，不能宣布飞行性能合格。路径角变化率不是机体俯仰角速度，垂直加速度不是机体操纵或过载限值。

TJ906比2000ft低32.480446ft；与取整解释可能相容并不能证明若2000ft为强制最低或定高时符合。16L的620m也不能自动满足600m/2000ft的所有限制类型。FAF、FAP与GP_CAPTURE继续分开，后二者为null；二次段只是条件高度连接，不是实飞GP捕获事件。
